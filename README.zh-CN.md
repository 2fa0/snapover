# Snapover

[English](README.md) | **简体中文**

在同一**局域网（LAN）**内的 Windows 和 macOS 电脑之间同步剪贴板。在一台电脑复制文字、图片、文件或文件夹，即可在另一台电脑粘贴。

## 功能

- 通过局域网同步文字、图片、文件和文件夹。
- 自动发现局域网内的电脑，也支持手动输入 IP 地址连接。
- 首次配对核对六位校验码，并在两台电脑上确认；连接采用 TLS，并记住已信任的设备。
- 查看复制历史、置顶常用内容和使用快速粘贴。
- 主动发送文件，直接保存到另一台电脑的接收文件夹。
- 关闭主窗口后继续在系统托盘或菜单栏运行并同步。

## 下载与安装

前往 [最新版本](https://github.com/2fa0/snapover/releases/latest)，选择对应电脑的安装包：

| 系统 | 安装包 |
| --- | --- |
| Windows 10/11，x64 | `Snapover-*-windows11-x64.zip` |
| macOS 13 及以上，Apple 芯片 | `snapover-*-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `snapover-*-amd64.dmg` |

**Windows：** 解压 ZIP，保留解压目录内的全部文件，运行 `Snapover.exe`。

**macOS：** 打开 DMG，将 `Snapover.app` 拷贝到「应用程序」，再从「应用程序」启动。

## 连接两台电脑

1. 在两台电脑上安装并启动 Snapover，连接到同一局域网。
2. 系统询问时，允许本地网络访问或防火墙连接。
3. 打开「连接设备」→「添加设备」，选择另一台电脑；如果自动发现不可用，可手动输入对方的局域网 IP 地址。
4. 核对两边相同的六位配对校验码，并在两台电脑上确认。
5. 在一台电脑复制内容，在另一台电脑粘贴。使用期间，两台电脑都需保持 Snapover 运行。

macOS 使用快速粘贴时，还需允许辅助功能权限。

## 更新

在「设置 → 关于与更新」或托盘／菜单栏的「检查更新」中检查新版本。更新文件经过签名，安装前会验证。也可以从 Releases 手动下载并安装新版。
