# 更新记录

## 0.7.2

- 修复主窗口复制历史底部的「复制、置顶、删除」被推出窗口的问题：隐藏标题栏后，顶部拖拽区域不再占用页面高度，窗口较高或较矮时这一行都完整显示在窗口内。

## 0.7.1

- 复制历史的类型筛选改为「全部、置顶、文本、图片、文件」，常用的置顶筛选靠近开头。
- 历史列表里文件和文本改用不同图标：文件、文件夹和图片是实心图标，文本是带文字行的空心文档，小尺寸下也能一眼分清记录类型。
- 快速历史去掉顶部标题和底部操作提示，同样的窗口高度能看到更多记录；辅助功能权限等会影响粘贴的状态仍会提示。
- 快速历史窗口可用鼠标拖拽右边、下边和右下角调整宽高，松手后记住，下次打开沿用上次的大小；限制在宽 280–1200、高 200–1000，并且不超过当前屏幕工作区。
- 拖快速历史的空白处（四周留白和搜索框与列表之间的缝隙）可以移动窗口，光标变为抓手；位置不记忆，下次仍贴在光标或托盘图标旁弹出。
- 发送窗口、拖放、Windows「发送到」、macOS Finder 服务和 `snapover-cli send file` 支持一次选择多个文件，按顺序逐个传输并显示整批进度；单个文件仍沿用文件大小上限，整批合计不受限，仍不支持文件夹。
- 升级 MyGo 到 0.7.3。

## 0.7.0

- 新增可选的 Tailscale IPv4 跨网络连接，默认关闭。支持手动添加地址、为已配对设备验证和保存独立的 Tailscale 地址，以及查看当前连接路径；首次配对仍需双方核对校验码并确认。
- 自动重连按同一设备依次尝试发现的局域网地址、已保存的局域网地址和 Tailscale 地址；明确指定的地址在首轮优先。关闭 Tailscale 或删除地址会停止相关连接与拨号，保留其他设备和局域网连接，文件发送始终绑定原目标设备。
- 文件历史改为只保存名称与目录预览，继续支持搜索、置顶和删除，不再保留正文或从历史重新粘贴文件。升级会移除旧文件历史快照并保留可读取的名称与预览；当前系统剪贴板里的文件仍可直接粘贴。
- 文件剪贴板旧缓存预算固定为 1 GiB，新接收另按实际大小预留空间。发送归档移入应用缓存；清理异常退出留下的过期接收与文本暂存文件，并保护正在进行的传输。
- 原图查看副本支持复用，容量上限为 128 MiB，后台清理超过 15 分钟的副本。历史存储设置可按需统计文件缓存、接收文件夹和损坏历史备份的占用，接收文件与备份仍由用户手动整理。
- Tailscale 自动化与编译验证已完成；Windows / macOS 真实跨网双机、不同 Tailscale 安装版本及中继链路验收仍待执行，详见 [实施计划](tailscale-plan.md#9-实机验收与完成条件)。

## 0.6.3

- 发送窗口拖放区改为虚线边框，拖入时平滑过渡到强调色，选中文件后改为实线；仍只接受单个文件。
- 主窗口从历史写回剪贴板成功后改为原生 Toast 提示；读取过程和失败仍显示在底栏。

## 0.6.1

- 文件和文件夹进入主界面与快速历史，列表分别显示文件名和文件夹名称；文件夹悬停预览展示一层树状结构，最多 20 项，超出时提示还有更多。
- 支持从文件历史重新复制粘贴、按文件名搜索、置顶和删除，文件快照计入历史容量，沿用置顶保护和清理规则。
- 保存独立文件快照，原文件移动、删除或接收缓存清理后仍可从历史粘贴；粘贴使用独立副本，删除历史不破坏当前文件剪贴板，取消粘贴会清理临时内容。

## 0.6.0

文件和文件夹接入统一剪贴板体验：在一台电脑复制，切到另一台电脑直接粘贴，无需打开发送窗口。

- 支持单文件、多选和文件夹，保留目录结构、空目录和空文件；复制图片文件按文件同步，复制图片像素仍按图片同步。
- 后台分块传输并校验，完整接收后才写入原生文件剪贴板；准备和传输进度显示在状态栏，不阻塞后续文字和图片同步。
- 文件剪贴板遵守自动／手动、暂停和只同步文本设置。新的复制优先，旧文件完成后不会覆盖新内容；剪切仅按复制处理，不删除源文件。
- 文件大小上限默认 200 MB，可在设置 → 文件同步中调整；剪贴板按整批内容合计，主动发送按单个文件计算，双方分别校验。
- 文件使用独立缓存，当前剪贴板引用的内容在应用重启后仍可粘贴，其他缓存定期清理。暂不支持符号链接、特殊文件及跨平台不兼容的文件名。
- 文件剪贴板需要双方升级到 0.6.0；与旧版连接时，文字和图片同步继续可用。原有主动发送文件入口保留。

## 0.5.1

- Windows 剪贴板暂时被占用时，在后台短暂等待并重试写入；重试期间若本地复制了新内容、暂停同步或连接已改变，则停止写入。
- 剪贴板写入失败时，收到的文字或图片仍保留在对端历史中，并向发送端报告实际结果。
- 同步失败、发送队列满或断线重连后，可以重新复制同一内容发送，避免被内容去重永久拦截。
- 普通日志记录剪贴板入队及对端处理结果，便于定位传输、剪贴板写入和历史保存问题；日志不包含复制的正文或图片数据。
- macOS 文件右键入口改为「服务 → Snapover 发送文件」，直接复用 Snapover 后台；启动时移除旧的 Automator 快速操作，避免继续产生 WorkflowServiceRunner。

## 0.5.0

这次更新集中补齐日常使用中的快捷入口、历史空间管理和同步结果反馈。

- **自定义快速历史快捷键**：可在设置中更换组合、恢复默认。组合被占用或设置保存失败时，保留原有快捷键。
- **历史容量管理**：默认内容上限 2 GB，可调整上限、刷新占用、清理全部未置顶记录。文本、原图、缩略图和预览均计入容量；超限先清最旧记录，置顶始终保留。删除失败会显示原因，残留文件会在下次维护时重试。
- **自动同步确认**：按条等待对端写入结果，正常成功保持安静，失败、超时和未确认断线显示原因；过期但尚未发送的内容不会在之后补发。
- **同时复制保留历史**：本地刚复制过时，收到的远端内容只存历史，不覆盖当前剪贴板。发送方收到单独的“已保存历史”结果；CLI 仍只把实际写入剪贴板视为成功。
- **移除远程桌面保活**：实机日志确认模拟鼠标无法可靠重置 RDP 空闲计时，已移除设置入口、后台输入模拟和专用诊断。
- **MyGo 更新**：依赖及构建工具从 v0.4.8 升级到 [v0.5.1](https://github.com/egoist/mygo/releases/tag/v0.5.1)。
