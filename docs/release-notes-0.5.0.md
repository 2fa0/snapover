# Snapover 0.5.0

这次更新集中补齐日常使用中的快捷入口、历史空间管理和同步结果反馈。

- **自定义快速历史快捷键**：可在设置中更换组合、恢复默认。组合被占用或设置保存失败时，保留原有快捷键。
- **历史容量管理**：默认内容上限 2 GB，可调整上限、刷新占用、清理全部未置顶记录。文本、原图、缩略图和预览均计入容量；超限先清最旧记录，置顶始终保留。删除失败会显示原因，残留文件会在下次维护时重试。
- **自动同步确认**：按条等待对端写入结果，正常成功保持安静，失败、超时和未确认断线显示原因；过期但尚未发送的内容不会在之后补发。
- **同时复制保留历史**：本地刚复制过时，收到的远端内容只存历史，不覆盖当前剪贴板。发送方收到单独的“已保存历史”结果；CLI 仍只把实际写入剪贴板视为成功。
- **远程桌面保活诊断**：日志记录跳过原因、输入发送及后续本地/WTS 空闲时间变化，帮助判断保活效果。相同原因下会话或查询状态变化也会记录。保活仍默认关闭。

- **MyGo 更新**：依赖及构建工具从 v0.4.8 升级到 [v0.5.1](https://github.com/egoist/mygo/releases/tag/v0.5.1)。完整测试、静态检查、macOS 原生窗口与快捷键验证、Windows 交叉构建通过。

本次审计问题与验证范围见 [代码审计](code-review-2026-10-15.md)。Windows RDP 实际保活效果及跨设备体验仍需实机验收。
