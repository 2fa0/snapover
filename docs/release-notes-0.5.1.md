# Snapover 0.5.1

- Windows 剪贴板暂时被占用时，在后台短暂等待并重试写入；重试期间若本地复制了新内容、暂停同步或连接已改变，则停止写入。
- 剪贴板写入失败时，收到的文字或图片仍保留在对端历史中，并向发送端报告实际结果。
- 同步失败、发送队列满或断线重连后，可以重新复制同一内容发送，避免被内容去重永久拦截。
- 普通日志记录剪贴板入队及对端处理结果，便于定位传输、剪贴板写入和历史保存问题；日志不包含复制的正文或图片数据。
- macOS 文件右键入口改为「服务 → Snapover 发送文件」，直接复用 Snapover 后台；启动时移除旧的 Automator 快速操作，避免继续产生 WorkflowServiceRunner。
